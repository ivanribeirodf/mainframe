# 💻 Tudo que aprendi: Do Zero ao Profissional

Bem-vindo(a) ao meu repositório sobre **Mainframe**! Aqui você encontrará anotações, exemplos práticos e códigos relacionados à jornada de aprendizado que percorri com foco em ambientes z/OS. Esta base de conhecimento é voltada tanto para iniciantes quanto para profissionais que desejam consolidar ou revisar conceitos importantes.


## 📚 Conteúdos Abordados

### 🏗️ Construção do Zero
- Conceitos básicos sobre o sistema z/OS
- Introdução ao TSO/ISPF
- Navegação por datasets e SDSF
- Montagem de ambientes de teste

### 🧾 JCL - Job Control Language
- Estrutura básica de um JCL
- Tipos de execução: batch, procedimentos e steps
- Manipulação de arquivos sequenciais e particionados

### 📊 Sort (DFSORT)
- Ordenação e filtragem de dados com `SORT`
- Uso de `INCLUDE`, `OMIT`, `SUM`, `OUTREC`, `BUILD`, etc.
- Exemplos práticos de uso em arquivos grandes

### 📁 GDG - Generation Data Group
- Definição, criação e uso de versões de arquivos
- Criação via JCL e manipulação com utilitários

### 💽 VSAM (KSDS, ESDS, RRDS)
- Conceitos e estrutura de arquivos VSAM
- Criação e manipulação com IDCAMS
- Acesso por COBOL e JCL

### ⚙️ Procedures e Utilitários
- PROCs catalogadas e in-stream
- Utilitários como `IEBGENER`, `IEBCOPY`, `IDCAMS`, `IEHLIST`, `IEFBR14`
- Automatização de tarefas

### 🚨 Tratamento de Abends
- Interpretação de códigos de retorno (RC)
- ABENDs comuns e como resolvê-los
- Análise de SYSOUT, SYSMSG e dump

### 🐚 REXX
- Scripts para automação no TSO
- Comandos ISPF e manipulação de arquivos
- Exemplos de interação com o usuário

### ⚙️ Assembler
- Introdução à linguagem
- Montagem e execução de programas
- Chamada de serviços do sistema

### 💼 COBOL
- Programas batch e online (CICS)
- Manipulação de arquivos (sequenciais, VSAM)
- Integração com JCL


## 🧠 Objetivo
- Este repositório foi criado como forma de consolidar todo o conhecimento adquirido durante meus estudos em ambientes mainframe. A ideia é que ele sirva como referência pessoal e também para outros profissionais da área.
